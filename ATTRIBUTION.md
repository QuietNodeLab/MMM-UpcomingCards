package. MagicMirror² (https://github.com/MagicMirrorOrg/MagicMirror) is a
separate MIT-licensed runtime dependency, not bundled source. The package MIT

system's font/emoji renderer; no font or emoji image collection is bundled.

include an MIT-licensed MMM-MonthlyCalendar patch solely for the shared-payload
regression. Preserve its adjacent license, including Jonathan Kolb's copyright
notice. It is not an end-user runtime dependency. No production image collection
